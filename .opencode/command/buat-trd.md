# /buat-trd — Buat/Update TRD Project-Level

Buat atau update TRD project-level dari PRD untuk: $ARGUMENTS

TRD adalah **dokumen hidup project-level**, bukan per-fitur.
Hanya di-update saat ada perubahan arsitektur, bukan tiap fitur baru.

## Langkah
1. Baca PRD dari ClickUp Docs (via @clickup)
2. Cari doc "TRD: [Nama Project]" di ClickUp Docs via @clickup
3. Jika sudah ada: baca → update bagian yang berubah
4. Jika belum ada: buat dari awal
5. Rancang arsitektur solusi
6. Definisikan API endpoints
7. Desain database schema
8. Buat implementation plan
9. Definisikan testing strategy
10. Simpan ke ClickUp Docs via @clickup

## Output
- TRD di ClickUp Docs
- Judul doc: "TRD: [Nama Project]"

Gunakan template di  sebagai referensi struktur.
