# Membuat PRD Baru

Buat PRD yang komprehensif untuk: $ARGUMENTS

## Langkah:
1. Pahami kebutuhan dari deskripsi
2. Identifikasi stakeholder dan target user
3. Definisikan goals dan success metrics
4. Buat functional requirements
5. Buat non-functional requirements
6. Identifikasi risiko dan mitigasi
7. Buat estimasi timeline
8. Definisikan acceptance criteria

## Template:
Gunakan template dari: templates/prd/PRD_TEMPLATE.md

## Output:
- Markdown dengan struktur jelas
- Tabel untuk requirements
- User stories dengan acceptance criteria
- Estimasi timeline dan resource

## Lokasi:
Simpan di: docs/prd/PRD_[NAMA]_[TANGGAL].md
