# /buat-prd — Buat/Update PRD Project-Level

Buat atau update PRD project-level untuk: $ARGUMENTS

PRD adalah **dokumen hidup project-level**, bukan per-fitur.
Berisi visi produk, target user, dan SEMUA fitur dalam satu dokumen.

## Langkah
1. Cari doc "PRD: [Nama Project]" di ClickUp Docs via @clickup
2. Jika sudah ada: baca → evaluasi apa yang perlu ditambah/diubah
3. Jika belum ada: buat dari awal
4. Definisikan target user dan goals
5. Tabel Functional Requirements — **append** fitur baru jika update, atau buat lengkap jika baru
6. Non-Functional Requirements
7. User Stories
8. Risiko & mitigasi
9. Timeline
10. Simpan ke ClickUp Docs via @clickup

## Output
- PRD di ClickUp Docs
- Judul doc: "PRD: [Nama Project]"
- Jika update: beri tahu user bagian mana yang berubah
