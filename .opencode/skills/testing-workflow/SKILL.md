# Testing Workflow Skill

## Testing Pyramid

### 1. Unit Tests
- Test individual components
- Mock external dependencies
- High coverage

### 2. Integration Tests
- Test component interactions
- Test API integrations

### 3. E2E Tests
- Test full user flows
- Test across browsers

## Coverage Goals
- Unit: >80%
- Integration: >60%
- E2E: Critical paths only
