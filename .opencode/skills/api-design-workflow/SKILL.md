# API Design Workflow Skill

## Design Process

### 1. Requirements Analysis
- Identifikasi use cases
- List resources dan operations
- Tentukan authentication method

### 2. Resource Design
- Resource-oriented design
- Naming conventions (plural nouns)
- Filter dan pagination

### 3. Endpoint Design
- HTTP methods
- Status codes
- Request/Response format
- Error handling

### 4. Documentation
- OpenAPI/Swagger spec
- API documentation
- Code examples

### 5. Testing
- Contract testing
- Integration testing
