# Documentation Workflow Skill

## Documentation Types

### 1. Technical Docs
- Architecture documentation
- System design
- API reference

### 2. User Docs
- User manuals
- Getting started guides
- Tutorials

### 3. Developer Docs
- Contributing guidelines
- Development setup
- Coding standards

## Writing Guidelines
- Clear and concise
- Use consistent style
- Include examples
- Keep updated
