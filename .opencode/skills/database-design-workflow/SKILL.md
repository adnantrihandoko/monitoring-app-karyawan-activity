# Database Design Workflow Skill

## Design Process

### 1. Requirements Analysis
- Identifikasi data requirements
- Analisis query patterns
- Pertimbangkan scalability

### 2. Conceptual Design
- Buat ERD
- Identifikasi entities
- Definisikan relationships

### 3. Logical Design
- Normalisasi
- Definisikan constraints
- Tentukan indexes

### 4. Physical Design
- Pilih database type
- Definisikan data types
- Plan partitioning

### 5. Implementation
- Create migration scripts
- Seed initial data
- Setup backup procedures
