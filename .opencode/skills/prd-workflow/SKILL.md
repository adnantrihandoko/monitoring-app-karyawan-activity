# PRD Workflow Skill

## Workflow Phases

### 1. Discovery
- Kumpulkan requirements dari stakeholder
- Analisis business needs
- Identifikasi target users

### 2. Drafting
- Gunakan template PRD
- Isi setiap section dengan lengkap
- Sertakan diagrams jika diperlukan

### 3. Review
- Present kepada stakeholders
- Kumpulkan feedback
- Iterasi berdasarkan feedback
- Dapatkan approval

### 4. Implementation
- Convert PRD ke technical spec
- Break down menjadi tasks
- Estimate effort
- Plan sprints

### 5. Tracking
- Monitor progress terhadap PRD
- Update status regularly
- Document deviations
